# Brazilian E-Commerce Sales Analysis – Power BI
## Project Overview
This project analyzes Brazilian e-commerce sales data using Microsoft Power BI.
The dashboard provides an interactive view of sales performance, customer behavior, product categories, delivery performance, payment methods, customer locations, and seller performance.
The objective of the project is to convert raw e-commerce data into meaningful business insights through interactive dashboards and KPIs.

## Dashboard Analysis
### 1. Sales Performance
The dashboard analyzes:
* Total revenue
* Total orders
* Average Order Value (AOV)
* Revenue trends
* Monthly order trends
* Year-over-year performance
* Revenue by product category
The dashboard reports total revenue of 14.21M and 98.67K total orders.
---
### 2. Product Category Analysis
The dashboard provides category-level analysis using:
* Revenue
* Orders
* AOV
* Average rating
* On-time delivery percentage
It also includes Top 10 categories by revenue and category-level performance comparisons.
---
### 3. Customer Analysis
Customer analysis includes:
* Revenue by customer state
* Top customer states by revenue
* Top customer cities by revenue
* Revenue by category and customer state
* Customer order behavior
---
### 4. Delivery Performance
The delivery analysis focuses on:
* On-time delivery percentage
* Late orders
* Late orders by month
* Average delivery days by category
* Late percentage by customer state
* Comparison of ratings between late and on-time orders
The overall on-time delivery percentage shown in the dashboard is 93.23%.
--
### 5. Customer Ratings
The dashboard analyzes customer satisfaction through:
* Average rating
* Positive review percentage
* Negative review percentage
* Rating distribution
* Average rating by category
* Rating comparison between late and on-time orders
The overall average rating is 4.03.
---
### 6. Payment Analysis
Payment analysis includes:
* Payment type share
* Payment value
* Number of orders
* Average Order Value by payment type
* Average installments
* Payment value trends
The dashboard shows credit card as the largest payment category by payment v
---
### 7. Seller Analysis
Seller performance is analyzed using:
* Total sellers
* Revenue per seller
* Revenue by seller state
* Top sellers by revenue
* Seller state and category performance
The dashboard reports approximately 3.095K total sellers.
